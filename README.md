# course-claude-api-testing

Repo thực hành sử dụng **Claude** (Claude Code / Claude API) để hỗ trợ các công việc kiểm thử phần mềm (software testing) — ví dụ: khảo sát một ứng dụng web, sinh tài liệu đặc tả yêu cầu (SRS), viết test case, v.v.

## Nội dung hiện có

| File | Mô tả |
|---|---|
| [SRS_Login_Module.md](SRS_Login_Module.md) | Tài liệu SRS (Software Requirements Specification) cho module Đăng nhập, được sinh ra từ việc khảo sát trực tiếp giao diện đăng nhập của CRM demo tại [crm.anhtester.com](https://crm.anhtester.com/authentication/login) (Perfex CRM demo). |
| [LICENSE](LICENSE) | Giấy phép MIT. |

## Mục đích

- Thực hành dùng Claude để tự động hoá các bước đầu của quy trình kiểm thử: khảo sát UI, sinh tài liệu đặc tả, chuẩn bị test case/test scenario.
- Lưu lại các tài liệu, script phục vụ cho khoá học/luyện tập về Claude API và kiểm thử phần mềm.
